# Contribuindo

Este projeto é mantido em português. Descreva alterações e motivos de modo claro.

Antes de mudar uma função, identifique seu módulo. Separe alterações de visual das alterações no backend; não misture refatorações grandes com mudanças de comportamento. Ao alterar o instalador, preserve a proteção contra remoção de arquivos que não pertencem ao Áudio Painel RC.

Para propor uma mudança, utilize uma branch, registre testes realizados e abra um Pull request para `main`. Evite enviar binários, dados pessoais, chaves ou arquivos gerados automaticamente. Anexe capturas da interface quando modificar o visual.
