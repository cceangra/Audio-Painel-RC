# Como contribuir

Todo o conteúdo de documentação pode continuar em **português**.

- Uma mudança por branch; commits curtos e descritivos.
- Antes de alterar o funcionamento de áudio, adicione um teste que reproduza o caso.
- Para mudanças de interface, concentre CSS em `src/interface/tema.cpp`.
- Mantenha a instalação sem `sudo` nem modificações silenciosas no ambiente.
- Preserve o comportamento de limpeza e os registros próprios do instalador.
- Nunca envie executáveis gerados, logs, preferências pessoais ou credenciais em commits.
- Abra Pull Requests com objetivo, arquivos alterados e resultados dos testes.

Veja [Arquitetura](ARQUITETURA.md) e [Guia do GitHub](GUIA-GITHUB.md).
