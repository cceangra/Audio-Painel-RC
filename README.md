# Áudio Painel RC

Aplicativo de gerenciamento de áudio para Linux, desenvolvido em **C++17**. Projeto com foco no Q4OS/Debian e Trinity Desktop, com integração a PipeWire/WirePlumber.

**Organização planejada:** interface gráfica e tema em `src/interface/`, áudio em `src/audio/`, componentes do sistema em `src/sistema/`, instalador em `src/instalador/`, fluxo principal em `src/aplicacao/`, testes em `src/testes/` e documentação em `docs/`.

Este repositório será atualizado com o código-fonte completo da versão **0.3.0**, sem os executáveis distribuídos.

> O código-fonte está sendo preparado para publicação. Consulte o histórico de commits para acompanhar a importação.
